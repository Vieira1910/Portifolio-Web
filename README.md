Portfólio pessoal desenvolvido para apresentar minha trajetória como **Desenvolvedor Front-End**, minhas habilidades, tecnologias e projetos desenvolvidos ao longo da minha jornada.

## **💻 SOBRE O PROJETO**

Este portfólio foi desenvolvido para reunir meus principais trabalhos e apresentar minha evolução no desenvolvimento web.

A proposta foi criar uma página que não fosse apenas uma apresentação pessoal, mas também uma forma de demonstrar na prática meus conhecimentos em **desenvolvimento Front-End, design e criação de interfaces**.

## **🎯 OBJETIVOS DO PROJETO**

O desenvolvimento do portfólio teve como objetivos:

- Criar uma apresentação profissional como desenvolvedor
- Demonstrar conhecimentos em **Front-End**
- Reunir projetos desenvolvidos em um único espaço
- Praticar criação de interfaces modernas
- Trabalhar com responsividade
- Desenvolver uma identidade visual própria
